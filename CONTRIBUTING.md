# Contributing

Install Node 24 and Git, run `npm ci`, then `npm test` and `npm run test:package`. For a host change, run the pinned Codex sequence in the README. Include the sanitized JSON and the expected exits with your pull request. Keep private traces out of the repository.

A new adapter needs a measured, reproducible run on its own target. Include a deliberate mismatch and a test for inconclusive evidence. Describe the exact tool operation and which response field carries the witness.
